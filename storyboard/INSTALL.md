# Установка: инструкция для Claude Code

Ты ставишь пользователю схему «Доска раскадровки»: локальную веб-доску, где пользователь пишет комментарии на кадрах своего
готового ролика, а ты читаешь их, правишь ролик и отвечаешь в ветках. Пользователь ничего не набирает в терминале: все шаги
делаешь ты. Ничего существующего не затирай: если файл или папка уже есть, покажи разницу и спроси.

## Установка

1. Скачай папку `storyboard` из репозитория, на который дал ссылку пользователь (клон во временную папку или загрузка
   файлов по сырым ссылкам). Нужна подпапка `tool/`.
2. Проверь Node.js: `node -v`, нужна версия 18 или новее. Если нет, скажи пользователю, что ставишь, и поставь
   (Windows: `winget install OpenJS.NodeJS.LTS`, macOS: `brew install node`, Linux: пакетным менеджером). После установки
   открой новый терминал, чтобы обновился PATH.
3. Проверь ffmpeg и ffprobe: `ffmpeg -version`, `ffprobe -version`. Если нет, скажи, что ставишь, и поставь (Windows:
   `winget install Gyan.FFmpeg`, macOS: `brew install ffmpeg`, Linux: `apt install ffmpeg` или аналог). Ключей, регистрации
   и платных сервисов эта схема не требует.
4. Скопируй содержимое `tool/` в `tools/storyboard/` корня проекта пользователя (папка, в которой открыта сессия; `tools/`
   создай, если нет). Если `tools/storyboard/` уже есть, сравни файлы и спроси, обновлять ли. Данные досок лежат в
   `videos/<проект>/storyboard/`, не в `tools/`, поэтому обновление инструмента их не трогает.

## Сборка доски по ролику

5. Спроси у пользователя: путь к готовому ролику (mp4, mov и другие форматы, которые читает ffmpeg; вертикальные и
   горизонтальные подходят), название ролика для шапки доски. Если у проекта есть расшифровка речи с таймингами слов
   (например, JSON из Whisper), используй её: слова попадут в подписи кадров. Без неё доска тоже работает, у кадров
   будет время вместо фразы.
6. Выбери короткое имя доски латиницей без пробелов (например `reel-01`). Оно станет папкой `videos/<имя>/storyboard/`.
7. Если есть слова с таймингами, приведи их к файлу JSON вида `[["слово", начало_сек, конец_сек], ...]`.
8. Собери доску из корня проекта:

   ```
   node tools/storyboard/build-board.mjs <имя> --video "<путь к ролику>" [--words слова.json] [--title "Название"]
   ```

   Параметры: `--every 2` шаг кадров в секундах, `--block 10` длина блока на доске в секундах (0 = один блок), `--max N`
   взять только первые N секунд, `--root` и `--videos` другая папка досок. Скрипт сам определит вертикальный это ролик или
   горизонтальный, положит в `videos/<имя>/storyboard/` файлы `board.json`, `film.mp4` (копия 720p для просмотра) и
   `frames/К001.jpg`, `К002.jpg` и так далее. `review.json` (комментарии пользователя) он не трогает.

## Запуск

9. Запусти сервер из корня проекта фоновым процессом, чтобы он не блокировал сессию: `node tools/storyboard/server.mjs`.
   Адрес http://localhost:4321. Если порт занят, добавь `--port 4322`. Сервер слушает только этот компьютер
   (`127.0.0.1`), параметр `--host` не меняй: доска пишет файлы на диск, в сеть её выставлять нельзя. На Windows
   пользователь может и сам запустить `tools\storyboard\start.cmd` двойным кликом (этот файл только для Windows).
10. Проверь, что доска отвечает: `http://localhost:4321/api/projects` должен вернуть имя доски. Если в приложении Claude
    есть панель браузера, открой там адрес, иначе дай пользователю ссылку.
11. Коротко доложи: что поставлено, адрес доски, сколько кадров собрано, что делать пользователю дальше (открыть доску,
    написать комментарии на кадрах и сказать «оставил комментарии»).

## Цикл правок

Пользователь пишет комментарии на доске и говорит «оставил комментарии» (или «прочитай доску»). Ты:

1. Читаешь правки: `node tools/storyboard/cli.mjs <имя>`. Это сводка по кадрам: оценка (`НУЖНА ПРАВКА`, `ВОПРОС`,
   `НРАВИТСЯ`), заметка, комментарии с `(id)` и моментом `⏱м:сс.с`, вложения `📎 путь`, ссылки. Строки с `[решено]` уже
   закрыты, их не переделывай. `--all` показывает всё, включая закрытое.
2. Смотришь, что он имел в виду. Момент `⏱` это секунда в ролике: вытащи кадр из оригинала командой
   `ffmpeg -ss <секунда> -i "<ролик>" -frames:v 1 <файл>.jpg` и посмотри. Вложения-картинки открой и посмотри, у
   вложений-видео вытащи несколько кадров `ffmpeg -i <файл> -vf fps=2 <файл>_%02d.jpg`. Пути вложений в сводке
   относительные от корня проекта.
3. Вносишь правки в ролик так, как это делается в проекте пользователя. Если комментарий неясен, не угадывай: ответь в
   ветке вопросом и оставь его открытым.
4. Отвечаешь в ветке под комментарием, коротко: что именно сделал (какой объект, что изменилось, с каких до каких
   секунд): `node tools/storyboard/cli.mjs <имя> reply <кадр> <id> "текст"`.
5. Закрываешь то, что сделано полностью: `node tools/storyboard/cli.mjs <имя> resolve <кадр> <id>`. Пользователь может
   открыть комментарий снова кнопкой на доске.
6. Если нужно оставить своё замечание к кадру без привязки к его комментарию:
   `node tools/storyboard/cli.mjs <имя> note <кадр> "текст"`.
7. Когда ролик пересобран, обнови доску той же командой `build-board.mjs` с новым файлом ролика и тем же именем.
   Комментарии останутся на своих номерах кадров. Если после правок изменился хронометраж и кадры сместились, скажи об
   этом пользователю.

Доска сама подтягивает твои ответы раз в несколько секунд, обновлять страницу не нужно. Все ответы идут от имени Claude,
писать комментарии от имени пользователя нельзя.

## Что нельзя

- Удалять `review.json`, `history/` и `files/` доски: там комментарии и вложения пользователя.
- Выставлять сервер в сеть и менять `--host`.
- Класть в доску ключи, пароли и чужие данные.

Если проект лежит в Git, предложи пользователю не коммитить `videos/*/storyboard/film.mp4` и `videos/*/storyboard/history/`
(спроси, добавить ли их в `.gitignore`).

## Формат board.json (для справки)

`build-board.mjs` пишет его сам. Если нужно собрать доску вручную или дописать описания кадров, поля такие:

```
{
  "title": "Название ролика", "duration": 43.2, "film": "film.mp4", "width": 2160, "height": 3840, "aspect": 0.5625,
  "blocks": [{"name": "0:00 – 0:10", "t0": 0, "t1": 10}],
  "frames": [{"id": "К001", "block": "0:00 – 0:10", "t0": 0, "t1": 2, "phrase": "речь в этом отрезке", "img": "frames/К001.jpg",
              "see": "что в кадре", "motion": "движение", "transition": {"type": "тип", "dur": "0,4 с", "why": "зачем"},
              "sound": "звук", "text": "текст в кадре"}],
  "patterns": [], "refs": []
}
```

Поля `see`, `motion`, `transition`, `sound`, `text` необязательны, их можно заполнить, чтобы пользователь видел описание кадра
рядом с видео. Блоки «Паттерны монтажа» и «Референсы» на доске появляются, только если в `patterns` и `refs` есть записи
(`patterns`: `code`, `name`, `how`, `where`, `img`; `refs`: `id`, `title`, `img`; картинки лежат внутри папки доски).

## Проверка

Файлы `tools/storyboard/{server.mjs,cli.mjs,build-board.mjs,start.cmd}` и `app/` на месте; `node --check` проходит для трёх
`.mjs`; `videos/<имя>/storyboard/board.json` читается, кадры и `film.mp4` существуют; `/api/projects` возвращает доску.
