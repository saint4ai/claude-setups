# Раздачи @saint4ai для Claude Code

Готовые схемы и паки навыков из роликов и курса onAI.academy. Руками ничего ставить не нужно: отдай Claude Code ссылку на
нужную раздачу и напиши «поставь мне это». Он сам сделает всё по `INSTALL.md` внутри. Руками только регистрация, оплата,
ключи и разрешения, если раздача их просит.

## Схемы в этом репозитории

| Папка | Что делает | Из ролика |
|---|---|---|
| [`opus-team`](opus-team/) | Opus думает, Sonnet пишет код, Haiku проверяет. Дорогая модель не тратится на рутину, лимиты тают медленнее | «Opus начальник», кодовое слово «тимлид» |

## Как добавить новую раздачу

Скопировать [`_template`](_template/) в папку с понятным именем, заполнить `README.md` (для человека) и `INSTALL.md`
(для Claude), добавить строку в таблицу выше. В текстах для людей нет длинных тире и штампов: точка, запятая или двоеточие. Ссылка для директа и автоматизации ведёт на папку:
`https://github.com/saint4ai/claude-setups/tree/main/<папка>`.
