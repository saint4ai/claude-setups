# Установка: общая инструкция для Claude Code

Пользователь дал ссылку на этот репозиторий или на папку в нём. Он ничего не набирает в терминале, ставишь ты.

1. Ссылка на папку (`…/tree/main/<папка>`): ставь только её, строго по `<папка>/INSTALL.md`.
2. Ссылка на весь репозиторий: покажи таблицу раздач из `README.md` и спроси, что ставить. Всё сразу не ставь.
3. Раздача из «Отдельных репозиториев»: открой её репозиторий и следуй его README.
4. Общие правила для любой раздачи: ничего существующего не затирай (если файл есть, покажи разницу и спроси); личные
   настройки (`~/.claude/settings.json`, `~/.claude/CLAUDE.md`) меняй только по ключам и блокам, которые названы в
   инструкции; в конце коротко доложи, что поставлено и что пользователю сделать дальше.
