# Claude видит статистику твоих соцсетей через Metricool

Metricool собирает цифры Instagram, TikTok, YouTube и LinkedIn, а Claude по ним отвечает: какие посты зашли и когда лучше выкладывать. В терминал ничего вводить не нужно.

Нужна подписка Claude Pro или Max. Бесплатный аккаунт Metricool подходит: данные за 30 дней и до 20 постов в расписании.

## Как подключить

1. В приложении Claude открой Customize, вкладка Connectors.
2. Найди Metricool в каталоге коннекторов и нажми Connect. Нет в каталоге: «+ Add», Add custom connector, имя Metricool, в поле URL адрес `https://ai.metricool.com/mcp` (это адрес подключения, в браузере он не открывается).
3. Войди в свой аккаунт Metricool.
4. Напиши Claude: «Когда мне лучше выложить рилс по моей статистике?»
