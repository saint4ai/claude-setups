# Команда в Claude Code: Opus думает, Sonnet пишет, Haiku проверяет

Самая дорогая модель не тратится на рутину. Opus планирует и принимает сложные решения, Sonnet пишет код, Haiku прогоняет
проверки. Цена за миллион токенов ответа: Opus 5.5 — $20, Sonnet 5 — $10, Haiku 4.5 — $5 (прайс Anthropic API, сентябрь
2026). На подписке то же самое означает, что лимиты расходуются медленнее.

## Как поставить

Ничего не нужно набирать в терминале. Открой Claude Code (в терминале или во вкладке Code приложения Claude) и напиши ему:

> Поставь мне эту схему: <ссылка на эту папку>. Следуй INSTALL.md.

Claude сам скопирует агентов и навык, включит режим `opusplan` и проверит, что всё на месте.

## Что появится

| Что | Модель | Что делает |
|---|---|---|
| основной чат в режиме плана | Opus | разбирает задачу, режет на шаги, решает, какие файлы трогать |
| основной чат при выполнении | Sonnet | ведёт работу по плану |
| агент `coder` | Sonnet | пишет код одного шага плана |
| агент `checker` | Haiku | прогоняет тесты, типы и сборку, коротко докладывает, что сломалось |
| агент `architect` | Opus | сложное решение по ходу работы и финальная проверка перед «готово» |
| навык `opus-team` | — | порядок работы: план → код по шагам → проверка → финальный разбор |

## Как работать

1. Дай большую задачу, например: «добавь оплату на сайт». Claude перейдёт в режим плана (если нет — включи его сам,
   в Claude Code это plan mode) — там думает Opus.
2. Прочитай план и согласись. Дальше Claude выполняет шаги: код пишет `coder`, после каждого шага `checker` прогоняет
   проверки.
3. Если по ходу встретилось сложное решение или проверка упала дважды подряд — вопрос уходит `architect`.
4. Перед тем как сказать «готово», `architect` смотрит итог целиком.

## Как проверить, что работает

Напиши Claude: «Покажи, какие у меня агенты и какая модель стоит по умолчанию». В ответе должны быть `coder`, `checker`,
`architect` и модель `opusplan`.

## Как убрать

Напиши Claude: «Удали схему opus-team: агентов coder, checker, architect, навык opus-team и верни модель по умолчанию».
