# Установка — инструкция для Claude Code

Ты ставишь пользователю схему «Opus думает, Sonnet пишет, Haiku проверяет». Пользователь ничего не набирает в терминале:
все шаги делаешь ты. Ничего существующего не затирай — если файл уже есть, покажи разницу и спроси.

1. Скачай папку `opus-team` из репозитория, на который дал ссылку пользователь (клон во временную папку или загрузка
   файлов по сырым ссылкам).
2. Скопируй агентов в пользовательскую папку, чтобы они работали во всех проектах:
   `agents/coder.md`, `agents/checker.md`, `agents/architect.md` → `~/.claude/agents/`.
   Если агент с таким именем уже есть — не перезаписывай, спроси пользователя.
3. Скопируй навык: `skills/opus-team/SKILL.md` → `~/.claude/skills/opus-team/SKILL.md`.
4. Включи режим модели `opusplan` в `~/.claude/settings.json`: добавь или замени только ключ `"model": "opusplan"`,
   остальные настройки оставь как есть. Если там уже стоит другая модель — скажи, какая, и спроси, менять ли.
5. Допиши в `~/.claude/CLAUDE.md` блок из `CLAUDE.md.snippet` (между метками `<!-- opus-team -->`). Если блок уже есть —
   обнови его, не дублируй.
6. Проверь: файлы на месте, `settings.json` — корректный JSON, в каждом агенте есть `name`, `description`, `model`.
7. Коротко доложи: что поставлено, какая модель теперь по умолчанию, что пользователю сделать дальше — открыть новую сессию
   Claude Code, чтобы агенты и навык подхватились, и дать первую большую задачу.
