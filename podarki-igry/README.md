# Подарки бесплатной игры «AI-агент»

Четыре навыка из уроков 1–4 бесплатной игры onAI.academy.

| Файл | Урок | Что делает |
|---|---|---|
| [Память проекта.md](Память%20проекта.md) | 1 | агент ведёт память проекта и помнит, на чём остановились |
| [Организатор дел.md](Организатор%20дел.md) | 2 | дела и сроки раскладываются в Google Диске и календаре |
| [Письмо по-человечески.md](Письмо%20по-человечески.md) | 3 | письма звучат как от человека, без штампов |
| [Презентация-рассказ.md](Презентация-рассказ.md) | 4 | презентация строится как история: проблема, цифры, решение |

## Как поставить

Скопируй ссылку на нужный файл и отправь агенту (Claude Code или Codex) фразу:

```
Установи навык по ссылке: <ссылка на файл>
```

Или скачай файл кнопкой скачивания справа над текстом, перетащи в поле агента и напиши «Установи этот навык».
