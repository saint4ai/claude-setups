# 4 коннектора для Claude: интернет, сайты, браузер и 300+ приложений

Коннектор даёт Claude доступ к сервису: он читает свежий интернет, разбирает сайты, открывает браузер и работает с вашими приложениями. Подключается за минуту, в терминал ничего вводить не нужно.

Нужна подписка Claude Pro или Max.

## Как подключить в приложении Claude

1. Открой приложение Claude (claude.ai/download) или claude.ai.
2. Слева Customize, вкладка Connectors, «+ Add», Add custom connector.
3. Имя любое, адрес коннектора из таблицы вставь в поле URL, нажми Add.
4. Если коннектор попросит войти, войди в свой аккаунт этого сервиса на его официальном сайте.

Адреса ниже не открываются как обычные страницы: это адреса подключения, их вставляют в Claude.

| Коннектор | Что делает | Адрес для Claude |
|---|---|---|
| Perplexity | читает интернет прямо сейчас, вход в аккаунт Perplexity | `https://api.perplexity.ai/mcp` |
| Firecrawl | разбирает любой сайт, ключ не нужен | `https://mcp.firecrawl.dev/v2/mcp` |
| Composio | 300+ приложений в одном коннекторе, вход в аккаунт Composio | `https://connect.composio.dev/mcp` |
| Playwright | открывает браузер и кликает за тебя | ставится в Claude Code, см. ниже |

## Playwright и всё сразу в Claude Code

Открой Claude Code и напиши ему:

> Подключи мне коннекторы по этой странице: https://github.com/saint4ai/claude-setups/tree/main/mcp-connectors. Следуй INSTALL.md.

## Как проверить

Напиши Claude: «Найди в интернете, что нового вышло у Anthropic на этой неделе, со ссылками». Ответ со свежими ссылками значит, что Perplexity работает.
