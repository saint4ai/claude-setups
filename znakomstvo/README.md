# Навык «Знакомство»

Навык из урока 1 бесплатной игры «AI-агент» onAI.academy. Агент задаёт 6 коротких вопросов по одному, потом предлагает 3–5 дел, которые возьмёт на себя, и сохраняет итог в файл «Обо мне.md».

## Как поставить

1. Скачай файл [Знакомство.md](Знакомство.md): открой его и нажми кнопку скачивания справа над текстом («Download raw file»).
2. В Claude открой вкладку Code и свою папку «Мой агент».
3. Перетащи файл в поле сообщения и отправь фразу:

```
Установи этот навык и проведи со мной знакомство по нему.
```

В Codex то же самое, файл добавь через «+».
