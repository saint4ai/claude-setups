# Промпты 6 эффектов из рилса «Слэш, и надпись встаёт за моей спиной»

Каждый эффект Claude Code собирает через [HyperFrames](https://github.com/heygen-com/hyperframes) поверх твоей записи. Кодовое слово под роликом: «ПРИЁМ».

## Как запустить

1. Открой Claude Code в папке, где лежат твоя запись и музыка.
2. Напиши ему: «Установи HyperFrames и его навыки». Он всё поставит сам.
3. Вставь промпт нужного эффекта и поменяй имена файлов на свои. Claude покажет превью и отрендерит MP4.

Снимай вертикально 9:16, сиди по центру, голова в верхней трети кадра, за спиной стена. Музыка без слов, около 120 ударов в минуту.

## 1. /text-behind-me (надпись встаёт за моей спиной)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из моего видео me.mp4, кусок 3 секунды с начала. Вырежи меня из фона (remove-background в HyperFrames) и собери три слоя: исходное видео снизу, надпись посередине, вырезанный я сверху.
Надпись одним словом «ПРИЁМ» (поставь своё слово): узкий жирный шрифт Oswald 700, ширина слова 860 px, высота букв 250 px, кремовый цвет #FFF1DC с тёмно-оранжевым торцом. Верх слова над моей макушкой, голова закрывает низ средних букв не больше чем на четверть.
Буквы встают с пола по одной: поворот по оси X с 90° до 0° вокруг нижнего края за 0,4 с с лёгким перелётом, последняя буква на сильную долю трека music.mp3 (посчитай доли через librosa).
От меня на надпись мягкая тень: сдвиг вправо и вниз на 24 px, размытие 30 px, прозрачность 35%. Края вырезки без светлого ореола. Камера медленно наезжает, 2,5% в секунду.
```

## 2. /glass-capsule-word (слово в капсуле жидкого стекла)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 3 секунды. Вырежи меня из фона (remove-background в HyperFrames).
Капсула жидкого стекла 830×110 px со словами «ПРОМПТ КАЖДОГО В КОНЦЕ»: размытие фона 18 px, насыщенность 180%, белая кромка 4 px, блик сверху, внутри медленно плывут пятна краски мяты и янтаря.
Капсула выдувается пузырём из петлички у меня в руке: растёт из круга 40 px с пружиной за 0,5 с и встаёт на груди. К петличке тянется тонкий стеклянный хвостик, он следует за рукой (найди петличку на кадрах и отследи её).
Потом капсула покачивается на 6 px, на сильных долях трека music.mp3 вздрагивает, по стеклу проходит блик.
```

## 3. /fisheye-lens (объектив «рыбий глаз»)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 2 секунды.
Вход: маленькая стеклянная линза 120 px летит на камеру и растёт за 0,35 с; когда её край выходит за кадр, включается «рыбий глаз».
Искажение бочкой силой 0,35 к краям, круг кадра диаметром 860 px по центру с мягким краем 60 px. За кругом то же видео: размытие 14 px, яркость 35%, тон лайма. По самому краю круга расхождение цветов на 3 px, на сильных долях от круга расходится светлое кольцо.
На каждую долю трека music.mp3 короткий наезд 1 → 1,06 → 1 за 0,2 с, как в скейт-видео.
```

## 4. /phone-pop (выхожу из экрана телефона)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 3 секунды. Вырежи меня из фона (remove-background в HyperFrames).
Положи видео в iPhone: экран 650×1380 px, скругление 90, титановая кромка 12 px, мягкая тень под телефоном. Телефон откидывается назад на 50° (perspective 1950 px, ось по нижнему краю), потом медленно доворачивается по оси Y на 6°.
Вырезанный я выхожу из экрана: голова и плечи поднимаются над верхним краем экрана, ниже края вырезка обрезана экраном и чуть темнее (тень от кромки), низ тела растворяется в экране. Выход за 0,4 с с пружиной: вырезка растёт с 0,72 до 0,9 и поднимается на 210 px. На экране остаётся пустая комната.
Телефон лежит на тёмном градиенте. В момент выхода из точки над кромкой экрана расходится светлое кольцо за 0,6 с.
```

## 5. /counter-badge (плашка со счётчиком)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 2 секунды. Вырежи меня из фона (remove-background в HyperFrames).
Из-за моего правого плеча выезжает плашка из матового стекла 320×150 px, скругление 40: «ЭФФЕКТ 5 ИЗ 6», подпись не меньше 36 px. Пока плашка за плечом, её перекрывает вырезанный я.
Цифра крутится барабаном вверх за 0,45 с с 1 до 5 и встаёт с толчком 1,08 → 1. Плашка наклонена на 4° и мягко пульсирует на каждую долю трека music.mp3. Число бери из настоящего счёта, без выдуманных цифр.
```

## 6. /grid-wall (стена из плиток за спиной)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 4 секунды, и пяти клипов fx1.mp4 … fx5.mp4. Вырежи меня из фона (remove-background в HyperFrames).
За моей спиной поднимается стена плиток 3×5: плитки встают волной от моего силуэта, ряд за рядом, поворот по оси X с 90° до 0° от нижнего края за 0,3 с. Зазор 18 px, скругление 28, в плитках куски комнаты без меня, за ними светлый градиент.
Плитки по очереди переворачиваются по оси Y на полудоли трека music.mp3 и показывают клипы fx1.mp4 … fx5.mp4 по кругу, остальные плитки остаются кусками фона. Вырезанный я стою перед стеной.
В конце dolly zoom за 1,4 с: я держу размер, стена уходит назад, и по краям появляются ещё два ряда плиток.
```
