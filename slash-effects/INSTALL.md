# Установка: инструкция для Claude Code

Ты ставишь пользователю HyperFrames, чтобы он собирал эффекты из промптов этой папки. Пользователь ничего не набирает в терминале: все шаги делаешь ты. Ничего существующего не затирай: если файл уже есть, покажи разницу и спроси.

1. Поставь HyperFrames и его навыки по инструкции репозитория https://github.com/heygen-com/hyperframes. Нет Node.js или FFmpeg: поставь их сам.
2. Попроси пользователя открыть Claude Code в папке, где лежат его вертикальная запись и музыка, и открыть новый чат, чтобы навыки подхватились.
3. Когда пользователь пришлёт промпт эффекта из папки `slash-effects/<рилс>/`, подставь имена его файлов вместо me.mp4, music.mp3 и других, сначала покажи превью, потом отрендерь MP4.
4. Коротко доложи: что поставлено и какой эффект пользователь может собрать первым.
