# Эффекты из рилсов «Слэш»

В каждом рилсе серии через «/» вбивается команда, и на ту же запись ложится новый эффект. Здесь промпты всех эффектов: Claude Code собирает каждый через HyperFrames поверх твоей вертикальной записи.

| Папка | Рилс | Кодовое слово |
|---|---|---|
| [`effekt`](effekt/) | «Слэш, и вокруг меня крутятся рилсы» | «ЭФФЕКТ» |
| [`priem`](priem/) | «Слэш, и надпись встаёт за моей спиной» | «ПРИЁМ» |
| [`kadr`](kadr/) | «Слэш, и кадр собирается сам» | «КАДР» |

## Как поставить

Ничего не нужно набирать в терминале. Открой Claude Code и напиши ему:

> Поставь мне HyperFrames по INSTALL.md отсюда: https://github.com/saint4ai/claude-setups/tree/main/slash-effects

Потом открой папку с нужным рилсом, скопируй промпт эффекта и поменяй имена файлов на свои.

## Что нужно

Компьютер и Claude Code. Node.js и FFmpeg Claude поставит сам.
