# Промпты 6 эффектов из рилса «Слэш, и вокруг меня крутятся рилсы»

Каждый эффект Claude Code собирает через [HyperFrames](https://github.com/heygen-com/hyperframes) поверх твоей записи. Кодовое слово под роликом: «ЭФФЕКТ».

## Как запустить

1. Открой Claude Code в папке, где лежат твои видео и музыка.
2. Напиши ему: «Установи HyperFrames и его навыки». Он всё поставит сам.
3. Вставь промпт нужного эффекта и поменяй имена файлов на свои. Claude соберёт ролик и отрендерит MP4.

Снимай вертикально 9:16, сиди по центру, лицо в верхней трети кадра. Музыка без слов, около 120 ударов в минуту.

## 1. /reels-orbit (вокруг меня по кругу крутятся мои рилсы)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из моего видео me.mp4, кусок 3 секунды с начала. Вырежи меня из фона (remove-background в HyperFrames) и собери три слоя: исходное видео, карточки, вырезанный я сверху.
Карточки: 8 кадров моих рилсов из папки reels (картинки 9:16), скругление 30 px, белая кромка 4 px, мягкая тень.
Они летят по наклонной орбите вокруг меня. Центр орбиты на уровне груди, радиус 600 px по ширине и 150 px по высоте. Карточки задней половины орбиты рисуй под вырезанным мной, чтобы они уходили за спину. Передняя половина идёт поверх меня. Задние меньше (масштаб 0,6) и темнее (яркость 0,5), передние крупнее (1,1). Поворот по оси Y по месту на орбите, до 35°.
Ритм: посчитай доли трека music.mp3 (librosa). На каждую долю орбита делает рывок на 45° с плавным торможением 0,3 с, между долями медленно вращается.
В начале карточки вылетают из центра за 0,6 с. По орбите тонкое светлое кольцо со свечением, его задняя половина тоже уходит за меня. Камера медленно наезжает, 2,5% в секунду. Музыка music.mp3.
```

## 2. /liquid-glass-graph (панель жидкого стекла с живым графиком)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 3 секунды. На уровне груди появляется панель жидкого стекла 1100×560 px, скругление 72: размытие фона 30 px, насыщенность 190%, белая кромка 3 px, внутри медленно плывут пятна мяты и янтаря, по стеклу проходит блик.
Панель вырастает из маленькой пилюли с пружиной за 0,4 с.
Внутри подпись «ТРЕК ПО ДОЛЯМ», крупно темп трека в BPM и живой график громкости моего трека music.mp3 за последние 2,6 с. Посчитай огибающую трека (RMS каждые 1/30 с) и темп через librosa, цифры бери только из трека.
График: линия со свечением и заливкой под ней, рисуется слева направо за 0,5 с. На каждой доле вертикальный пунктир, точка на конце линии пульсирует в такт.
```

## 3. /match-cut (склейка по совпадению)

```text
Сделай в HyperFrames склейку по совпадению из моих записей a.mp4, b.mp4, c.mp4, d.mp4. Они сняты в одной позе, свет в комнате разный.
Найди лицо на каждой записи (центр и ширину) и выровняй записи масштабом и сдвигом, чтобы лицо стояло в одной точке кадра.
Видео в карточке на 86% кадра, скругление 64, белая кромка 5 px. Фон вокруг карточки красится в цвет света текущей записи.
Меняй запись на каждую долю трека music.mp3 (при 120 BPM каждые 0,5 с). На срезе вспышка белым 0,09 с и толчок карточки с 1,05 до 1.
Вокруг лица стоят неподвижные белые уголки-рамка, на срезе они чуть вздрагивают. На последней записи камера наезжает к лицу на 10%.
```

## 4. /ios-toggles (тумблеры iOS меняют видео)

```text
Сделай в HyperFrames вертикальный ролик из видео me.mp4, кусок 2,5 с. Снизу с пружиной въезжает карточка настроек iOS: светлое матовое стекло, скругление 52, три строки «Тёплый свет», «Плёнка», «Чёрно-белый». Справа у каждой тумблер iOS: выключен серый, включён зелёный #34C759, ручка скользит с лёгким перелётом.
Тумблеры включаются по одному на доли трека (0,25 с, 0,75 с, 1,25 с), и каждый сразу меняет видео за 0,18 с:
тёплый свет: sepia 0,4, насыщенность +45%, оттенок −14°;
плёнка: зерно поверх в режиме overlay, виньетка, контраст +14%;
чёрно-белый: grayscale 1, контраст +12%.
```

## 5. /over-the-shoulder-zoom (2.5D-наезд из-за плеча)

```text
Сделай в HyperFrames 2.5D-наезд из видео me.mp4, кусок 2 с. Вырежи меня из фона (remove-background в HyperFrames). Два слоя: фон (исходное видео) и вырезанный я.
За 1,2 с с плавным разгоном и торможением:
фон уезжает влево на 110 px, поворачивается по Y на 10°, растёт на 10%, размывается до 9 px и темнеет на 30%;
вырезанный я растёт до 1,6 вокруг лица, сдвигаюсь вправо на 130 px, поворачиваюсь по Y на −12°, под мной мягкая тень.
Камера как будто заходит из-за плеча к лицу, а комната отъезжает назад.
```

## 6. /stack (стопка эффектов и сетка)

```text
Возьми пять готовых эффектов (клипы fx1.mp4 … fx5.mp4) и сделай в HyperFrames вертикальный ролик со стопкой.
Каждый клип карточкой 640×1138 px, скругление 44, белая кромка, падает сверху в центр через каждые 0,25 с (полудоли трека 120 BPM). Поворот у каждой свой, от −5° до +5°, сдвиг до 35 px. Падение 0,16 с с ускорением, на ударе стопка дрожит 0,2 с.
Потом за 0,45 с стопка раскладывается в сетку 3×2 (карточки 350×622, зазор 35 px). В шестой ячейке маленькая стопка кадров, верхний уходит на каждую долю. В углу каждой карточки метка с названием эффекта моноширинным шрифтом. Клипы в карточках играют по кругу.
```
