# Промпты 6 эффектов из рилса «Слэш, и кадр собирается сам»

Каждый эффект Claude Code собирает через [HyperFrames](https://github.com/heygen-com/hyperframes) поверх твоей записи. Кодовое слово под роликом: «КАДР».

## Как запустить

1. Открой Claude Code в папке, где лежат твоя запись и музыка.
2. Напиши ему: «Установи HyperFrames и его навыки». Он всё поставит сам.
3. Вставь промпт нужного эффекта и поменяй имена файлов на свои. Claude покажет превью и отрендерит MP4.

Снимай вертикально 9:16, лицо в верхней половине кадра. Музыка без слов, около 100–120 ударов в минуту.

## 1. /carousel-spin (кадр крутится гранями)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из моего видео me.mp4, кусок 3 секунды.
Разрежь кадр на 9 вертикальных полос по 120 px. Каждая полоса это трёхгранная призма: на первой грани исходное видео, на второй то же видео крупнее в 1,45 раза с центром на глазах, на третьей видео, отражённое по горизонтали.
Швы между полосами прорисовываются сверху вниз за 0,15 с. На сильные доли трека music.mp3 (посчитай доли через librosa) призмы поворачиваются по оси Y на 120° волной слева направо: шаг 0,03 с, поворот 0,28 с с лёгким перелётом. Боковины призм тёмные, в щелях виден мягкий зелёный градиент.
Три поворота, после третьего швы сходятся и кадр снова целый. Камера медленно наезжает и чуть поворачивается, чтобы была видна толщина призм.
```

## 2. /split-screen (я напротив себя)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из двух кусков моего видео: me.mp4 и me2.mp4, по 3,5 секунды.
Сверху в центр кадра падает вертикальная планка 45 px в косую оранжево-кремовую полоску и встаёт с толчком. Кадр делится пополам: слева me.mp4, справа въезжает справа за 0,3 с me2.mp4, отражённый по горизонтали, чтобы мы смотрели друг на друга. В каждой половине лицо по центру своей половины.
На сильную долю трека music.mp3 половины меняются местами хлыстом за 0,25 с. На следующую сильную долю правая половина сменяется другим дублем сдвигом вниз, а планка уезжает так, что половины делят кадр 60 на 40.
```

## 3. /spotlight (свет гаснет, бьёт прожектор)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 3 секунды.
На сильной доле трека music.mp3 яркость за 2 кадра падает до 18%, как будто выключили свет. Через 0,1 с бьёт прожектор: две короткие вспышки, потом тёплый круг диаметром 570 px с мягким краем 90 px, внутри видео в полную яркость. Сверху из-за кадра к кругу идёт светлый конус с прозрачностью 12%.
Круг следит за моим лицом (найди лицо на каждом кадре и сгладь путь). На долю круг перепрыгивает в левый нижний угол и обратно, на следующую долю сужается до 390 px на глазах.
```

## 4. /freeze-chalk (стоп-кадр, мел обводит силуэт)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 2,5 секунды. Вырежи меня из фона (remove-background в HyperFrames), вырезка нужна только для контура.
Видео идёт на скорости 0,8. На три сильные доли трека music.mp3 кадр замирает на 0,25 с, и белый мел обводит мой силуэт: линия 8 px с шероховатым краем, рисуется по контуру за 0,25 с.
Потом стоп-кадр с белой кромкой 10 px уезжает влево карточкой: поворот до −7°, уменьшение до 0,88, смаз по горизонтали 30 px. Под ним видео продолжается с того же места.
```

## 5. /timeline (кадр уезжает на монтажный стол)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4 (кусок 3 секунды) и четырёх клипов fx1.mp4 … fx4.mp4.
Камера отъезжает за 0,6 с: видео сжимается в окно превью 9:16 высотой 740 px вверху по центру, скругление 28. Ниже собирается монтажный стол на светлом фоне: линейка с таймкодом, дорожка звука с настоящей волной music.mp3, дорожка видео.
На дорожку видео по одному на полудолю падают клипы fx1.mp4 … fx4.mp4, у каждого подпись не мельче 30 px. Плейхед едет по долям, окно превью показывает тот клип, над которым стоит плейхед. В конце в пустом слоте дорожки печатается название следующего клипа.
```

## 6. /cinema-bars (кино-шторки 2,39:1)

```text
Сделай в HyperFrames вертикальный ролик 1080×1920 из видео me.mp4, кусок 2 секунды, скорость 0,8.
Сверху и снизу съезжаются чёрные шторки, между ними остаётся полоса 1080×452 px (это 2,39:1) на уровне глаз. Шторки встают за 0,3 с, на торце у полосы косые оранжево-кремовые полоски 45 px.
На сильную долю трека music.mp3 по полосе проходит анаморфный блик: тонкая оранжевая линия #ff8a3d через весь кадр с горячей точкой, которая едет слева направо за 0,3 с.
На следующую сильную долю шторки дышат: полоса расширяется на 30 px вверх и вниз и возвращается за 0,45 с. На последнюю долю шторки раскрываются.
```
