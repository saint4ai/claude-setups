2. <куда что скопировать: агенты → ~/.claude/agents/, навыки → ~/.claude/skills/<имя>/>
3. <какие ключи настроек поменять, если нужно, — только эти ключи>
4. <что дописать в ~/.claude/CLAUDE.md — блоком между метками <!-- имя -->>
